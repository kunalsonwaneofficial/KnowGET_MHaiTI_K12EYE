# Monitoring

Foundation directory for the observability stack delivered in **P1-M06 —
Enterprise Observability & DevOps Platform** and matured in **P5-D04**.

Planned assets: OpenTelemetry collector configuration, Prometheus scrape
configs, dashboards, and alert rules. Intentionally empty at P1-M01 — the
`@knowget/logging` package provides the structured-logging foundation that these
tools will consume.
