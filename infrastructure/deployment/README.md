# Deployment

Foundation directory for deployment manifests and infrastructure-as-code,
delivered in **P1-M06** and hardened by **P5-D05 (DevSecOps / Release
Engineering)** and **P5-D06 (Business Continuity / DR)**.

container orchestration manifests, and release/rollback automation. The
`Dockerfile.*` and `docker-compose.*` files under `../docker` are the current
containerization baseline.
